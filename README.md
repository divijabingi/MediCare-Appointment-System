# 🏥 MediCare Appointment Management System

A full-stack web application developed using **Java, Spring Boot, Spring MVC, React.js, and MySQL** for managing doctors, clients, appointments, and medical records. The application provides secure authentication, role-based authorization, and RESTful APIs to enable seamless communication between the frontend and backend.

---

## 🚀 Features

### 👨‍⚕️ Doctor Management
- Add, update, view, and delete doctor details
- Manage doctor profiles and availability

### 👤 Client Management
- Client registration and login
- Manage client profile information

### 📅 Appointment Management
- Book appointments with doctors
- View, update, and cancel appointments
- Track appointment details

### 📋 Medical Records
- Create and manage medical records
- View patient medical history

### 🔐 Security
- JWT-based authentication
- Role-based authorization using Spring Security
- Secure REST API endpoints

## 🏗️ Architecture

The backend follows a layered architecture consisting of:

- Controller Layer
- Service Layer
- Repository Layer
- Entity Layer

This architecture improves modularity, maintainability, and separation of concerns.

## ▶️ Getting Started

### Clone the repository

```bash
git clone <repository-url>
```

### Backend

1. Open the backend project in Eclipse or IntelliJ IDEA.
2. Configure MySQL database credentials in `application.properties`.
3. Run the Spring Boot application.

### Frontend

```bash
cd frontend
npm install
npm start
```

The application will start on the configured ports.
